## Selected Projects

### 1. Spatiotemporal Traffic Forecasting & Congestion Intelligence
*Machine Learning | Predictive Analytics | In Progress*

Developing a forecasting pipeline to investigate how traffic conditions vary with time and historical traffic patterns.

- Perform exploratory data analysis and temporal feature engineering using Python, Pandas, and NumPy.
- Compare Linear Regression, Random Forest, XGBoost, and LSTM models.
- Evaluate predictions using MAE, RMSE, and R².
- Use SHAP to investigate feature contributions and model behavior.

**Initial reported results:** Approximately 0.91 R², 2.9 MAE, and 4.8 RMSE.

**Focus:** Predictive modeling, feature engineering, model comparison, and explainable machine learning.

### 2. Thermal Camouflage Detection Using Deep Learning
*Deep Learning | Computer Vision | Image Segmentation*

Investigated whether thermal-like image representations could support the segmentation of camouflaged objects.

- Applied grayscale conversion and contrast enhancement using OpenCV and NumPy.
- Implemented a U-Net segmentation model using PyTorch.
- Used Albumentations for image augmentation.
- Evaluated model performance using IoU, Dice score, precision, and recall.

**Reported results:** Approximately 72% IoU, 78% Dice score, 75% precision, and 80% recall on the evaluation dataset.

**Focus:** Deep neural networks, image preprocessing, segmentation, and model generalization.

### 4. Narrative Consistency & Claim Verification
*NLP | Semantic Retrieval | Evidence Evaluation*
